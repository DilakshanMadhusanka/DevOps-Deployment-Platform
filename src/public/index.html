GitHub Actions CI/CD

Automated pipeline triggered on push/PR to main. Runs Node.js test runner, builds multi-arch Docker image with Buildx, scans for CVEs with Aqua Trivy, pushes to GHCR, and executes kubectl rollout status with automatic rollback on failure.

Multi-Stage Docker

Dockerfile & docker-compose.yml

Hardened multi-stage node:20-alpine image with dumb-init, non-root user (UID 1001), built-in HEALTHCHECK against /health/live, and full local orchestration with Nginx, Prometheus, Alertmanager, and Grafana.

Kubernetes Manifests

Zero-downtime RollingUpdate (maxSurge: 25%, maxUnavailable: 0), Pod anti-affinity, startup/liveness/readiness probes, HorizontalPodAutoscaler, PodDisruptionBudget, and scripts for rolling updates & rollbacks.

Production API gateway with upstream load balancing, passive health checks, connection keepalive pools, rate limiting zones, gzip compression, security headers, SSE streaming support, and /nginx_status stub metrics.
